Contributing annotations

To contribute new annotated frames from WV roadway footage:

  1. Download Label Studio (free, open-source)
  2. Import the labeling config XML when creating a new project (use "Custom template")
  3. Import your dashcam frames and annotate using rectangular bounding boxes
  4. Export as YOLO format (File → Export → YOLO)
  5. Submit via the repo's Issues page or open a pull request adding your export to data/wv_exports_all/

Local Inference App

The Sign Mapper processes dashcam video locally — inference and GPS interpolation require Python and a CPU (GPU optional). No data leaves your machine.

sign_mapper — Flask web app

Upload a dashcam video, a GPS sidecar file (.srt or .csv), and a YOLO checkpoint. The app extracts frames at 2 fps, runs inference, clusters detections spatially, and exports a GeoJSON file for ArcGIS or for viewing on the map tab above. 

git clone https://github.com/jordan-jacob/wvsignclassification
cd wvsignclassification/sign_mapper
pip install -r requirements.txt
python app.py
# open http://localhost:5000

One-time setup size: the app itself is small, but installing ultralytics pulls in torch (~2 GB with CUDA, ~500 MB CPU-only). This is expected and unavoidable for ML inference — a one-time download, not the app's own size. The Flask app uses opencv-python-headless (no GUI libraries) to keep the rest of the footprint minimal.

GPS sidecar requirement: most action cameras (DJI, GoPro, Rexing) embed GPS as subtitle tracks in .srt format alongside the video. Check your camera's export settings. A .csv with timestamp,lat,lon columns is also accepted.
