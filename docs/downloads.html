Downloads & Resources

Run the Sign Mapper locally, download model checkpoints, and get the annotation dataset!

Run locally

Requirements: Git, Python 3.10+

git clone https://github.com/jordan-jacob/wvsignclassification
cd wvsignclassification/sign_mapper
pip install -r requirements.txt
python app.py

Then open http://localhost:5000 in your browser.

Optional: ExifTool (for automatic GPS extraction)
Download from exiftool.org for free and add it to your PATH. Without it, you'll needa GPS sidecar file (.srt or .csv) to run the app.

Note: On some systems, use python3 instead of python. The first run will download about 1-2 GB of python machine learning dependencies. This is a one-time download.

Annotation Dataset

WVDOH Sign Annotations: Label Studio Export

These are the bounding-box annotations of WVDOH dashcam frames in YOLO format. This datasets contains 22 annotation classes, which are then remapped to the 9-class taxonomy at data prep time.

Export format
YOLO (bounding box, normalized)
Annotation tool
Label Studio
Annotation classes

Training classes
9 (WVDOH taxonomy)
Dataset
Kaggle Dataset

See labeling_config.xml for the Label Studio config and class colors I used.

Process for contributing annotations:

  1. Install Label Studio
  2. Import the labeling config XML (use "Custom template")
  3. Annotate frames with rectangular bounding boxes
  4. Export as YOLO format (File → Export → YOLO)
  5. Open a pull request adding your export to data/wv_exports_all/
